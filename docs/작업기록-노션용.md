# 네이버 마케팅 사이트 만들기 — 작업 기록 ①  설계도(PRD)

> 📅 2026-11-14 · 도구: Claude Code (데스크톱 앱) · 사용한 스킬: leaderpl-site-prd
> 오늘의 목표: 사이트를 만들기 전에 **설계도(PRD) 한 장**을 완성한다. 사이트 코드는 아직 만들지 않는다.

---

## 1. 처음 보낸 프롬프트

```
leaderpl-site-prd 스킬로 내 사이트 설계도(PRD)를 만들자.
오늘 만들 것: 나는 네이버 마케팅을 하고 있어. 이걸 홍보하는 사이트를 만들어보고싶은데
블로그글 발행이나 플레이스 세팅및 관리 클립 인스타 등을 운영해 이런 서비스별 금액과
서비스에 맞춘 사이트를 설계도를 만들어봐

나한테 한 번에 한 질문씩 물어봐 줘. 질문은 10개 안팎으로.
분위기, 문의를 저장할지, 관리자 페이지가 필요한지도 꼭 물어봐 줘.
내가 모르겠다고 하면 고를 수 있는 보기 2~3개를 줘.
질문은 내가 보기를 눌러서 고를 수 있는 질문 카드(AskUserQuestion)로 띄워 줘.
다 끝나면 docs/PRD.md 파일로 저장하고, 첫 화면에 들어갈 내용을 다섯 줄로 요약해 줘.
아직 사이트는 만들지 마.
```

💡 **잘 된 점:** "한 번에 한 질문", "보기 카드로", "아직 만들지 마"처럼 **진행 방식**까지 정해 주니 대화가 흐트러지지 않았다.

---

## 2. 인터뷰 — 질문 카드 10개

| # | 질문 | 내 답 |
|---|---|---|
| 1 | 가장 오면 좋겠는 손님은? | 동네 가게 사장님 |
| 2 | 그 손님은 어디서 나를 알고 오나? | 네이버 검색·블로그 |
| 3 | 문의 전에 가장 궁금해할 것은? (여러 개) | 서비스별 가격, 진행 과정·기간, 계약 조건 |
| 4 | 서비스별 가격은? | 직접 입력 (아래 5번 표 참고) |
| 5 | 나를 믿게 할 증거는? (실제로 있는 것만) | 운영 사례 화면 |
| 6 | 딱 하나 누르면 좋겠는 버튼은? | 카카오톡 문의 |
| 7 | 꼭 정확해야 하는 연락 방법·계약 조건은? | 직접 입력 (아래 5번 표 참고) |
| 8 | 사이트 분위기는? | 고급스러운 |
| 9 | 문의를 저장하고 관리자 페이지(/admin)에서 볼까? | 예, 저장 + 관리자 |
| 10 | 문의 폼에서 이름·연락처 외에 하나 더 받는다면? | 가게 이름·업종 |

💡 **배운 점:** 가격이나 연락처처럼 **정확해야 하는 것은 보기에서 고르지 않고 직접 써서** 보냈다. 클로드는 숫자를 지어내지 않고 내가 쓴 그대로만 적었다.

## 3. 결과물 ① — docs/PRD.md 저장

설계도 13칸: 한 줄 정의 · 손님 · 궁금한 것 · 믿게 할 증거 · 버튼 · 페이지 구성 · 문의 폼 · 정확한 사실 · 이번에 안 넣을 것 · 첫 화면 문장 후보 · 다음에 할 것 · 만드는 방법 · 만드는 순서

**페이지 구성 (한 페이지, 위→아래)**
1. 첫 화면 — 한 문장 + [카카오톡 문의] 버튼
2. 서비스 소개 — 블로그 / 플레이스 / 클립 / 인스타 카드 4개
3. 서비스별 가격표
4. 진행 과정 — 사전 상담 → 세부사항 결정 → 월 단위 운영
5. 운영 사례 화면
6. 후기 자리 (비워 둠)
7. 계약 조건·자주 묻는 질문
8. 문의 폼 + 카카오톡 문의 버튼

**이번에 넣지 않을 것:** 회원가입·로그인, 온라인 결제, 손님이 사진 올리기, 알림 메일, 여러 페이지 구성

---

## 4. 첫 화면 다섯 줄 요약

1. **큰 문장:** 사장님은 장사에만 집중하세요. 네이버 마케팅은 제가 맡겠습니다.
2. **작은 문장:** 블로그 · 플레이스 · 클립 · 인스타를 월 단위로 대신 운영합니다
3. **가격:** 블로그 월 15건 40만원 · 플레이스 세팅·관리 월 35만원 · 클립 월 10건 30만원 · 인스타 별도 문의
4. **조건:** 1개월 단위 계약 · 사전 상담 후 세부사항 결정 · 상담 오전 9시~저녁 11시
5. **버튼:** [카카오톡 문의] + 아래쪽 문의 폼(이름·연락처·가게 이름·업종)

⚠️ **클로드가 짚어 준 점:** 운영 사례와 후기가 비어 있으면 처음 보는 사장님이 망설일 수 있다 → 캡처 2~3장만 있어도 달라진다.

## 5. 수정한 내용 — 가격 변경

보낸 프롬프트:
```
가격은 수정할께 블로그 월 15건 40만원 플레이스 세팅및 관리 월 35만원 클립 월 10건 30만원 인스타는 별도 문의
```

| 서비스 | 처음 | 수정 후 |
|---|---|---|
| 블로그 기본 발행 | 월 15건 50만원 | **월 15건 40만원** |
| 네이버 플레이스 세팅 및 관리 | 월 50만원 | **월 35만원** |
| 네이버 클립 | 월 12건 35만원 | **월 10건 30만원** |
| 인스타 발행 | 별도 문의 | 별도 문의 |

**계약 조건 (내가 쓴 그대로):** 최소 계약 1개월 단위 · 사전 상담 후 세부사항 결정 · 상담 가능 시간 오전 9시~저녁 11시 · 연락은 카카오톡

## 7. 운영 사례 캡처 모자이크

보낸 프롬프트: 네이버 검색 결과 캡처 2장 + `상호들은 다 모자이크 처리를 해주면 좋겠어`

**가린 것**
- 사진 1 (안락동 맛집): 가게 이름, 건물 간판, 리뷰 닉네임 2개, 잘린 다음 가게 이름
- 사진 2 (서면 사주): 가게 이름 2개, 간판 사진 3곳, 간판 전화번호

**남긴 것:** 업종, 리뷰 수, 영업 시간, 동네 이름 → 어떤 사례인지는 알 수 있게

- 저장: `assets/cases/case-1.jpg`, `assets/cases/case-2.jpg` (원본은 저장소에 넣지 않음)
- 설계도 4번 "믿게 할 증거"에 추가
- ✅ Commit: `운영 사례 캡처 2장 모자이크 처리 후 추가`
