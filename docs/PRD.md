# 사이트 설계도(PRD) — 네이버 마케팅 대행 (사이트 이름 미정)

작성일: 2026-11-14 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
동네 가게 사장님을 위해 네이버 블로그 발행, 네이버 플레이스 세팅·관리, 네이버 클립, 인스타그램 발행을 월 단위로 대신 운영해 주는 마케팅 대행 서비스.

## 2. 손님
- 누가: 동네 가게 사장님 (식당·카페·미용실처럼 네이버 플레이스가 중요한 오프라인 가게)
- 어디서 알고 오나: 네이버 검색·블로그 (예: "플레이스 관리 대행" 검색, 내 블로그 글을 보고 들어옴)

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 서비스별 가격 — 블로그·플레이스·클립·인스타 각각 얼마인지
2. 진행 과정·기간 — 신청하면 무엇을 해 주고, 어떤 순서로 진행되는지
3. 계약 조건 — 최소 계약 기간, 세부사항은 어떻게 정하는지

## 4. 믿게 할 증거 (실제로 있는 것만)
- 운영 사례 화면 (네이버 검색 결과 캡처 2장, 상호·간판·리뷰 닉네임·전화번호 모자이크 완료)
  - assets/cases/case-1.jpg — "안락동 맛집" 검색 결과 (소고기구이, 리뷰 2,783)
  - assets/cases/case-2.jpg — "서면 사주" 검색 결과 (운세·사주 가게 2곳)
  - 사진 설명에는 캡처에 보이는 사실만 쓴다. 순위·매출 같은 성과는 사용자가 말해 주기 전엔 쓰지 않는다.
- 경력·고객 수·성과 숫자: 넣지 않는다 (사용자가 말한 것 없음)
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 카카오톡 문의
- 누르면: 카카오톡(아이디 sunhea0729)으로 연결
- 보조: 카톡이 부담스러운 사장님을 위해 아래쪽에 문의 폼 1개 (Supabase 저장)

## 6. 페이지 구성 (한 페이지, 위에서 아래로)
1. 첫 화면 — 한 문장 + [카카오톡 문의] 버튼
2. 서비스 소개 — 블로그 / 플레이스 / 클립 / 인스타 4가지 카드
3. 서비스별 가격표 — 8번 가격 그대로 (인스타는 "별도 문의")
4. 진행 과정 — 사전 상담 → 세부사항 결정 → 월 단위 운영 시작 (단계별 기간은 미정)
5. 운영 사례 화면 (캡처 자리)
6. 후기 자리 (비워 둠)
7. 계약 조건·자주 묻는 질문 — 1개월 단위, 사전 상담 후 결정, 상담 시간
8. 문의 폼 + 카카오톡 문의 버튼 한 번 더

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 가게 이름·업종
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격:
  - 블로그 기본 발행: 월 15건 40만원
  - 네이버 플레이스 세팅 및 관리: 월 35만원
  - 네이버 클립: 월 10건 발행 30만원
  - 인스타 발행: 별도 문의
- 계약: 최소 계약 기간 1개월 단위로 진행 / 사전 상담 후 세부사항 결정
- 시간: 상담 가능 시간 오전 9시 ~ 저녁 11시
- 위치: (미정 — 온라인 서비스라면 생략 가능)
- 연락 방법: 카카오톡 sunhea0729
- 부가세 포함 여부: (미정)

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 고급스러운 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel
  - 사이트: https://naver-marketing-site.vercel.app · 관리자: https://naver-marketing-site.vercel.app/admin
  - 저장소: https://github.com/sunhea0729-oss/naver-marketing-site (main에 푸시하면 자동 배포)
  - 문의 표: Supabase `inquiries` (이름·연락처·가게 이름/업종·동의·상태), RLS 켜짐
  - 사이트 이름은 임시로 "가게 마케팅" — 정해지면 index.html 로고·제목·바닥글을 바꾼다

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
